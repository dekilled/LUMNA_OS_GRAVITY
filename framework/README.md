# GraviTy Framework

Framework para criação de aplicações no LUMNA OS usando Gravity + Clay.

## Abordagem
Pré-processador: arquivos `.gt` (estilo HTML + script) são transformados em C puro que usa Clay.

## Estrutura
- `preprocessor/` — gerador de código
- `componentes/` — componentes reutilizáveis (.gt)
- `runtime/` — helpers usados pelo código gerado
